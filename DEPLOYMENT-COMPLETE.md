## 🎓 UNDERSTANDING THE SYSTEM

### What Will Happen Next

1. **Inngest Cron Fires** (30-min cycle)
   - Automatically triggers signer-orchestrator function
   - No manual action needed

2. **Mission Fetched**
   - Queries `SELECT * FROM missions WHERE status = 'pending'`
   - Orders by priority (CRITICAL first)
   - Takes next available mission

3. **Agent Assigned**
   - Router checks `mission.assigned_to` field
   - Routes to correct agent:
     - `signer` → Signer (manual decisions)
     - `operator` → Operator (infrastructure)
     - `researcher` → Researcher (analysis)
     - `scribe` → Scribe (content)

4. **AI Executes**
   - Formats mission as prompt
   - Calls `callAI()` function
   - Tries Groq first
   - Falls back to Gemini if needed
   - Continues through chain until success

5. **Results Logged**
   - Stores AI response in `mission_results`
   - Logs execution details to `mission_logs`
   - Updates mission status to `in_progress`

6. **Next Cycle**
   - Waits 30 minutes
   - Repeats for next mission
